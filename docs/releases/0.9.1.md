# Birja 0.9.1 — Historical price charts

- Crypto charts show Coin Metrics Community USD reference prices and daily closes across the day, week and month ranges. The source is attributed in the chart.
- Featured and catalog stocks show TradingView's delayed chart for the selected listing. The week view covers five trading days. Availability depends on TradingView's symbol coverage.
- Simulator orders use the existing execution quotes and risk checks independently of chart availability.

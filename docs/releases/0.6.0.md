# Birja 0.6.0 — Multiple strategy portfolios

Users can run independent investing experiments in up to ten private portfolios.
Each new portfolio receives its own $10,000 virtual starting balance once.

## Included

- Create and rename portfolios; add, edit or clear an optional description.
- Compare cash, value and return in an overview, then select a portfolio to trade.
- Keep cash, holdings, fees, cost basis, trades, dividends and History isolated.
- Preserve existing investments in the first portfolio without another grant.
- Delete any portfolio after named confirmation, including one holding assets
  or the last active portfolio. Deletion freezes the experiment and keeps its
  financial records private; it does not sell assets or transfer money.
- Exact current0023 and retained recovery, original-request replay, restricted
  verified-TLS migration and explicit incompatible rollback refusal.

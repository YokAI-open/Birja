# Birja0.6.2 — Deployment collation compatibility

The deployment readiness check incorrectly rejected the standard unversioned
C collation used by the portfolio-name index. PostgreSQL documents C/POSIX as
stable bytewise collations; their absent version is expected.

Recognize only those known built-in definitions. Database version mismatch,
invalid indexes, unknown absent versions and genuine versioned-collation drift
remain blocking checks. No catalogue-version refresh, reindex or financial/schema
change is needed. Third-party dependencies and stock activation remain unchanged.

References: [PostgreSQL18collations](https://www.postgresql.org/docs/18/collation.html),
[version mismatch handling](https://www.postgresql.org/docs/18/sql-altercollation.html).

Exact qualification and actual deployment results are recorded separately.

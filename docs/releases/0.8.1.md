# Birja 0.8.1 — Stock catalog and trading activation

- Search NYSE and Nasdaq common shares by company name or ticker. The first
  reconciled catalog contains 4,898 listings and preserves distinct share
  classes, including the NYSE dot and slash ticker forms.
- During the regular session, open an eligible stock in the selected portfolio
  and buy or sell whole shares using current IEX bid and ask quotes. The
  scheduler checks reported halts and supported corporate actions for selected
  stocks, held positions and pending entitlements.
- The protected rollout uses PostgreSQL schema 0027 and recovery profile v8.
  Production verification records the exact deployed source and an original
  simulated buy and sell outside the initial 20 listings.

Stock availability follows the current listing and provider evidence. The
source snapshot contained 25 listings that Alpaca marked as nontradable.
They remain part of search.

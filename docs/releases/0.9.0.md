# Birja 0.9.0 — Markets and workspace redesign

- Browse stocks and crypto in the redesigned Markets workspace. Closed
  stocks can show their last verified price and next session countdown.
- Open and manage strategy portfolios from cards, and see independent
  value trends as daily observations accumulate after rollout.
- Use the redesigned trade tickets, filter History by activity and asset,
  and sign in with the updated email-code screen.
- This release includes the historical chart interface. Live historical
  feeds remain disabled while their production data-use scope is open.
- The production rollout upgrades the database to schema 0028 on a
  separate datastore copy, with encrypted backups and verified restores.

# Birja 0.7.0 — Interface redesign

- Browse and search assets in the redesigned Markets workspace, with clearer
  asset details and a direct path to the trade ticket.
- Open strategies from the portfolio cards. A selected portfolio brings its
  value, return, allocation and filterable holdings together.
- Review trades, dividends and other recorded events in expandable History
  cards.
- Use the shared navigation and door icon to sign in or out. The redesigned
  screens were reviewed at phone and desktop widths and at native 200% zoom.

This release needs no database migration or new configuration. Existing
balances, holdings and financial records are preserved. Live stock activation
remains a separate follow-up.

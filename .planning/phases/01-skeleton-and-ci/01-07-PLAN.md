## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-24 | Elevation of Privilege | ci.yml GITHUB_TOKEN | mitigate | Workflow-level `permissions: contents: read`; `pull_request` trigger only (no `pull_request_target`); no secrets referenced |
| T-01-25 | Tampering | third-party actions | mitigate | Only official actions (actions/*, docker/*, astral-sh/setup-uv) pinned to major tags; SHA pinning deferred, accepted for MVP |

| T-01-27 | Repudiation / Tampering | merge of failing code | mitigate | Single required `ci-pass` check via branch protection when D-01 allows; otherwise accepted deviation recorded in PROJECT.md |
| T-01-28 | Information Disclosure | option-public visibility change | mitigate | History scanned for secrets and `.env` before switching; explicit second confirmation; Phase 1 has no real secrets (.env.example placeholders only) |
| T-01-29 | Information Disclosure | CI logs | mitigate | `docker compose logs` only on failure; app logs exception class names only (plan 02); CI uses .env.example placeholder passwords |

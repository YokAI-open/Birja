API contract (binding; 04-08 implements the server side). All money/quantity values are decimal strings in plain notation (never exponent form).
  POST /api/v1/trades/quote  body {symbol, side: "buy"|"sell", amount_usd?: string, quantity?: string}  (exactly one of amount_usd/quantity; amount_usd only with buy)
    200 Quote = {symbol, side, input_kind: "usd"|"quantity", input_value, mid, as_of, age_seconds: int, exec_price, quantity, notional, fee, cash_delta (signed), cash_before, cash_after, held_before, held_after, whole_position: bool}
  POST /api/v1/trades  body = quote body + {expected_mid: string, idempotency_key: uuid string}
    201 Fill (new) / 200 Fill (replay, identical body) = {trade_id: int, created_at, symbol, side, input_kind, input_value, mid, as_of, exec_price, quantity, notional, fee, cash_delta, cash_after}
  GET /api/v1/holdings/{symbol} -> 200 {symbol, quantity}
  Errors: body {detail: {code, message}}; codes: not_authenticated 401, csrf_failed 403, unknown_coin 404, stale_price 409, price_changed 409 (detail.quote = Quote), idempotency_conflict 409, below_minimum / insufficient_cash / insufficient_quantity / order_too_large 422. Pydantic validation 422 has an array detail (no code).

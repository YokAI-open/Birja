### W2 — WARNING: STRIDE registers use generic mitigations rather than concrete threats

All 18 registers repeat the same three grouped category descriptions and

migration file and says Task1 enforces an "owner/source/session boundary";

plans reference the underlying threat IDs and evidence validation instead of
inventing a Markdown-session boundary. Keep the exact existing issue35 risk

source/receipt relationship instead of a fabricated code link.

## Phase Goal

**As a** friend of the owner, **I want to** open https://birja.nist.one and sign in with a code emailed to me, **so that** I can use Birja without anyone running it locally for me.

<objective>
Create the prod secrets and the prod checkout, then rehearse the full deploy on the host through loopback only, before the code goes through the release process. The user adds the Resend key themselves. The rehearsal deploys the feature branch through `DEPLOY_REF`, runs the smoke script and the CSP spec through a host-resolver rule, and proves idempotency and rollback. Bugs found here are fixed on `feature/deploy-nist-one`, so `main` receives working scripts.

Why a rehearsal: D-05 puts the first prod deploy on `main` after a PR, a release and a tag. Any deploy-script bug found only after that would need a hotfix cycle. The rehearsal is not public: there is no DNS record for birja.nist.one until 02.1-09, and ufw admits only Cloudflare ranges.
Scope statement (D-05): this rehearsal is loopback-only and does not count as a deploy. There is no DNS record for birja.nist.one, and the plan checks that before and after. The first public deploy is still main-only, in 02.1-09, after the release in 02.1-08.
Output: /etc/birja/prod.env, /srv/birja, the birja-prod stack running on loopback, the smoke script green, and any fixes committed.
</objective>

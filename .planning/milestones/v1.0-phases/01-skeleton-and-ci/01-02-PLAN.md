<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client -> /api/v1/health | Unauthenticated, public endpoint (will be reachable through nginx in Phase 6) |
| backend -> Postgres / Redis | Credentials from environment |
| test runner -> database | A misconfigured URL could point tests at a non-test database |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03 | Information Disclosure | services/health.py, api/v1/health.py | mitigate | Response limited to Literal enums (status/db/redis); exceptions logged by class name only; test asserts body keys are exactly status, db, redis |
| T-01-04 | Information Disclosure | core/config.py | mitigate | DB/Redis URLs `Field(repr=False)`; never logged; loaded from env, no hardcoded secrets in app code |
| T-01-05 | Information Disclosure | main.py docs routes | mitigate | docs_url/redoc_url/openapi_url = None when ENV=prod |
| T-01-06 | Denial of Service | health checks | mitigate | asyncio.timeout(3) per check, Redis socket timeouts 2s, asyncpg connect timeout 5s, statement_timeout and idle_in_transaction_session_timeout 30s |
| T-01-07 | Tampering | tests vs dev DB | mitigate | tests/guard.ensure_test_stack refuses any DB/Redis not on 127.0.0.1:55432/56379 with a `_test` database, before fixtures run |
| T-01-08 | Information Disclosure | docker-compose.test.yml | accept | Throwaway test passwords, tmpfs data, ports bound to 127.0.0.1 only |
| T-01-SC | Tampering | uv dependencies | mitigate | Only packages approved in 01-01; versions pinned; uv.lock committed; `uv sync --locked` |
</threat_model>

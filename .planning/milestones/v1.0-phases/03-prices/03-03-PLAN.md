  @dataclass(frozen=True) class Candidate: anchor: Decimal; count: int
  Decision = Literal["accept", "accept_confirmed", "reject_invalid", "reject_spike"]
  def parse_price(raw: object) -> Decimal | None        # str only; Decimal(raw); None on InvalidOperation, non-finite, <= 0
  def mid_from_ticker(entry: object) -> Decimal | None  # entry["b"][0] bid, entry["a"][0] ask; None if missing/invalid or bid > ask;
                                                        # mid = ((bid + ask) / 2).quantize(Decimal("1e-8"), rounding=ROUND_HALF_EVEN); None if mid <= 0
  def evaluate_price(last_good: Decimal | None, new: Decimal, candidate: Candidate | None, *,
                     max_move: Decimal = Decimal("0.25"), confirm_tol: Decimal = Decimal("0.05"),
                     confirm_n: int = 3) -> tuple[Decision, Candidate | None]

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08 | Tampering | price values from Kraken (bug, glitch, MITM) | mitigate | `parse_price`/`mid_from_ticker` accept only finite positive Decimal strings and non-crossed books; `evaluate_price` rejects >25% moves unless confirmed by 3 polls within 5%; httpx verifies TLS by default; 100% coverage gate in CI |
| T-03-09 | Denial of service (to us and Kraken) | fetch_tickers retries | mitigate | Max 3 attempts, exponential backoff 1/2 s + jitter, deterministic errors not retried; caller polls every 60 s from one container |
| T-03-10 | Spoofing / SSRF | request target | mitigate | Fixed `TICKER_URL` constant; pairs only from the DB seed; no user input reaches the client |
| T-03-11 | Information disclosure | KrakenError messages / logs | mitigate | Errors carry only Kraken error strings, status codes or exception class names; no headers, env or secrets |
| T-03-12 | Tampering | tests hitting the live API | mitigate | respx with `assert_all_mocked=True`; grep check that tests contain no literal Kraken host; the single A7 live GET is a documented one-off outside the suite |
